# ISSUE-038: 语言包加载前调用 t() 误报缺键

- **状态**: done
- **优先级**: P3
- **区域**: public/js/i18n.js

## 问题

app.js 构造函数在 i18n.init() 之前调 ui.generateDisplayName()，后者要取 deviceNames.adjectives / deviceNames.nouns。此时 translations 还是空对象，t() 必然取不到值并打两条 "Missing translation" 警告。设备名随后会在 init() 里用正确语言重新生成，所以只是噪声——但它会淹没真正的缺键告警（排查时曾据此误判为语言包不全，实际 9 个语言包的键是齐的）。

## 修复方案

t() 在 translations[locale] 与 translations[fallbackLocale] 都为空时不打警告；init() 载入语言包后警告恢复有效。
