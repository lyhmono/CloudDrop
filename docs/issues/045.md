# ISSUE-045: 复制图片走 fetch(dataUrl)，被 CSP connect-src 拦截在生产环境必然失败

- **状态**: done
- **优先级**: P2
- **区域**: public/js/chat.js, tests/chat-dataurl.test.mjs

## 问题

copyImageToClipboard 用 `fetch(dataUrl)` 把 data:URL 转 Blob。_headers 的 CSP 是
`connect-src 'self'`，不含 data:，浏览器会直接拒绝该 fetch（生产页面实测返回
Failed to fetch）。开发时不起 Worker（不带响应头）根本测不出来，属于「部署后才显形」
的坏点：线上点击聊天图片的复制按钮 100% 失败，只弹"复制失败"。

## 修复方案

新增 dataUrlToBlob 手工解码（base64 与 percent-encoded 两种形态，缺 MIME 回退
image/png，非法输入抛错由调用方兜底），不再经过 fetch，也不为此放宽 CSP —— 该
connect-src 正是防止密钥材料被外带的防线。tests/chat-dataurl.test.mjs 用
「fetch 必然失败探针」锁定解码路径不再触碰 fetch。
