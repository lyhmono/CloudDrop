# ISSUE-034: 分块清理整库清空，跨标签页抹掉正在接收的分块

- **状态**: done
- **优先级**: P1
- **区域**: public/js/chunkStore.js, public/js/webrtc.js

## 问题

chunkStore.pruneAll() 用 clear() 清空整个 clouddrop-chunks，而它挂在 WebRTCManager 构造函数里；new WebRTCManager 位于 connectWebSocket()，所以每次重连、换房、开新标签页都会执行一次。IndexedDB 是同源共享的，于是开第二个标签页会把另一个标签页正在接收的大文件分块一起抹掉，传输到 file-end 时被判为不完整而丢弃。

## 修复方案

改为 pruneStale()：分块写入附带时间戳（{ d, t }），只回收时间戳早于 6 小时的残留。6 小时高于单文件上限 10GB 走中继（约 1MB/s）的最长耗时，因此活跃分块永远不会被误删；无时间戳的旧格式条目按残留处理，getAllChunks 做兼容解包。模块内缓存 promise，保证每次页面加载只实际扫一次。
