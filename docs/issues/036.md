# ISSUE-036: smoke 测试在 Windows 本地无法运行

- **状态**: done
- **优先级**: P2
- **区域**: tests/smoke-ci.mjs

## 问题

npm run smoke 在 Windows 上有两个专有问题：

1. spawn('npx.cmd') 被 Node ≥18.20 拒绝（CVE-2024-27980 之后禁止不经 shell 直接 spawn .cmd/.bat），直接 EINVAL 退出。
2. stopWrangler 用 process.kill(-pid) 发进程组信号，但 Windows 上负 pid 会抛 ESRCH，导致 wrangler 收不掉、脚本挂住不退出。

## 修复方案

win32 下给 spawn 加 shell: true；win32 下改用 taskkill /pid <pid> /T /F 收掉整棵进程树。Linux CI 行为不变。实测跑完 workerd 归零、8798 端口释放。
