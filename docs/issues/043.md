# ISSUE-043: webSocketError 不清理 peerWsCache，失效连接残留

- **状态**: done
- **优先级**: P3
- **区域**: src/room.ts

## 问题

peerId→WebSocket 缓存只在 webSocketClose 里剔除条目；异常断线（网络中断/超时）
按 issue-022 的注释只触发 webSocketError、不触发 close，于是 error-only 的连接会把
失效 WS 一直留在 peerWsCache 里，被后续 broadcast 反复遍历尝试发送。缓存只有等
Durable Object 休眠重建才恢复，长时间存活的房间会持续累积无效条目。

## 修复方案

把 close 里那段按 attachment.id + 身份匹配剔除缓存的逻辑抽成 prunePeerCacheEntry，
close 与 error 两个 handler 共用。与 handleLeave 的 WeakSet 去重协同，双触发也只清一次。
